# 决策记录纪律（分层时机与维护知识）

> 来源：SKILL.md「📜 决策记录纪律」→「记录时机（分层）」（v1.3.0 外置，真源同步）。
> 触发时机：保存/退出补录决策时如需确认分层归属、维护 skill 文档时读取。
> 轻决策格式与状态标记见 SKILL.md「决策记录纪律」一行式要点（保存流程实时使用，保留在正文）。
> 本文件为 skill 操作指令，由 SKILL.md 索引行引用，勿单独修改。

### 记录时机（分层）

| 类型 | 时机 |
|:---|:---|
| 重大决策（影响方向 / 难逆转 / 消耗资源） | 对话中**即时确认**：Claude 主动询问「这条记入决策记录吗？」 |
| 日常决策 | 保存/退出时统一回顾补录（强制） |

### 决策滚动归档（体积收敛）

- **阈值**：架构决策记录 > 30 条 或 CLAUDE.md 整体 > 20KB → 保存流程触发归档
- **动作**：最旧批次滚入项目内 `.archive/decision-archive-YYYYMMDD.md`（按归档日命名，可多次追加）
- **索引**：CLAUDE.md「架构决策记录」顶部留一行：`（决策归档：YYYY-MM-DD 前 N 条 → .archive/decision-archive-YYYYMMDD.md）`
- **隐私**：`.archive/` 必须进 .gitignore（含内部细节，绝不进 git/发布）；归因调查顺读归档（见 docs/attribution.md）

### 重决策 → ADR

难逆转、有真实权衡的决策落 `docs/adr/`（结构见 docs/adr-guide.md）。
