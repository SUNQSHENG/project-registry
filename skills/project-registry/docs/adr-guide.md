# 重决策 → ADR 指南

> 来源：SKILL.md「📜 决策记录纪律」→「重决策 → ADR」（v1.3.0 外置，真源同步）。
> 触发时机：遇到难逆转、有真实权衡的决策需要落 ADR 时。
> 本文件为 skill 操作指令，由 SKILL.md 索引行引用，勿单独修改。

难逆转、有真实权衡的决策落 `docs/adr/`，CLAUDE.md「架构决策记录」留一行索引：

```
- 2026-08-08 — ADR-0001 <决策标题>（状态：✅已执行）
```

ADR 结构：`# ADR-000N <标题>` + Status / Date / Context / Decision / Consequences。

轻决策（影响小、可逆）记入 CLAUDE.md「架构决策记录」一行式（格式见 SKILL.md「决策记录纪律」），不落 ADR。
